# Content Engine Output Repository

This repository contains content produced by the Concord Content Engine for human review and approval.

## How to review

1. Navigate to the run folder (e.g., `runs/run-013/`)
2. Read the **REVIEW.md** file for a summary of scores and what to look at
3. Review the content files:
   - `blog.md` — Blog post (primary deliverable)
   - `linkedin.md` — LinkedIn post
   - `email.md` — HubSpot email
4. Check the `review-panel/` folder for detailed scoring and debate transcripts
5. Leave feedback via GitHub Issues or PR comments

## Approval workflow

- **APPROVE** — Comment "APPROVED" on the review PR
- **REVISIONS** — Add comments on specific lines, the engine will revise
- **REJECT** — Comment "REJECTED" with rationale
