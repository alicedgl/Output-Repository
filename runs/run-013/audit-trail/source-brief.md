## Competitive Differentiators: AI-Native vs. AI-Assisted

This distinction is a KEY MESSAGE for the blog. Source materials:

### What "AI-native" means (Concord positioning)
- AI is built into the platform, not a separate add-on
- AI Assistant, Summarization, Extraction, and Document Generation work together as an integrated suite
- Included in all plans at no additional cost (competitors charge extra)
- 26-second contract reviews vs. 92 minutes manual
- Extraction transparency: see exactly where data came from
- **Source:** `context/context/features/ai-assistant.md`:197-203, `context/context/product/competitive-differentiators.md`:67-85

### What "AI-assisted" (bolt-on) looks like
- ContractSafe: basic data extraction and tagging only
- ContractWorks: basic AI for search and tracking
- PandaDoc: no advanced contract analytics
- Juro: basic document creation assistance only
- Dropbox Sign: limited to form field recognition
- DocuSign CLM: AI requires higher-tier plans or add-ons
- **Source:** `context/context/product/competitive-differentiators.md`:79-85

### The difference for CFOs specifically
AI-native means:
1. **Ask and get answers**: Natural language queries across entire portfolio (not just keyword search)
2. **Risk detection before P&L impact**: Auto-extracted deadlines and automated reminders (not manual tracking in spreadsheets)
3. **Reports on demand**: AI-enriched data in reports (not empty fields waiting for manual entry)
4. **Portfolio intelligence**: Bulk extraction and analysis across thousands of contracts (not one-at-a-time review)

AI-assisted (bolt-on) means:
1. You still ask IT or legal to run queries
2. You still rely on someone remembering to check a spreadsheet
3. Reports only contain what someone manually entered
4. Portfolio-level analysis remains a consulting project, not a Tuesday afternoon

**Source:** Synthesized from feature docs and competitive-differentiators.md. The specific contrast framing is editorial interpretation of documented capabilities.
